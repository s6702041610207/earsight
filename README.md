# EarSight v1

แอปแจ้งเตือนเสียงรอบตัวด้วยข้อความ ไอคอน สี และการสั่น สำหรับผู้บกพร่องทางการได้ยิน
Flutter + TensorFlow Lite + YAMNet ประมวลผลบนโทรศัพท์ทั้งหมด

## เริ่มใช้กับ Claude Code

1. แตกไฟล์ zip ไว้ในเครื่อง แล้วเปิดโฟลเดอร์ `earsight` ใน Claude Code
2. เปิด BlueStacks (instance Android 9 Pie 64-bit หรือ Android 11) แล้วเปิด ADB: Settings > Advanced > Android Debug Bridge จดพอร์ตไว้ (เช่น 127.0.0.1:5555)
3. พิมพ์คำสั่งนี้ให้ Claude Code:

> อ่าน CLAUDE.md แล้วติดตั้งโปรเจกต์ให้ครบตามหัวข้อ "ติดตั้งครั้งแรก" รัน flutter analyze กับ flutter test ให้ผ่าน แล้วรันแอปบน BlueStacks ที่ ADB 127.0.0.1:5555

ต้องมี Flutter 3.27 ขึ้นไปและ Android Studio (ใช้แค่ Android SDK) ในเครื่องก่อน
ถ้ายังไม่มี ให้ Claude Code ช่วยติดตั้งได้

## ฟีเจอร์ v1

- เตือน 6 เสียง: สัญญาณไฟไหม้, ไซเรน, แตรรถ (อันตราย) / เคาะประตู, กริ่ง (ต้องสนใจ) / มีคนพูดใกล้ๆ (แจ้งให้ทราบ)
- หน้าเตือนเต็มจอ: ชื่อเสียงตัวใหญ่ + ไอคอน + สีประจำเสียง เสียงอันตรายกะพริบจนกว่าจะแตะปิด
- สั่นต่างกันตามระดับ: อันตราย = ยาวแรง 4 ครั้ง, ต้องสนใจ = สั้น 2 ครั้ง, แจ้งให้ทราบ = เบา 1 ครั้ง
- ปุ่มเริ่ม/หยุดฟังขนาดใหญ่ และแถบระดับเสียง
- ประวัติเสียงย้อนหลัง (เก็บในเครื่อง)
- ตั้งค่า: เปิด/ปิดแต่ละเสียง, ความไว 3 ระดับ, เปิด/ปิดการสั่น, ดูตัวอย่างหน้าเตือน, โหมดทดสอบ

## ความเป็นส่วนตัว

ฟังเฉพาะตอนกดเริ่ม ไม่บันทึกเสียง ไม่ส่งเสียงขึ้นอินเทอร์เน็ต ประวัติเก็บแค่ชื่อเสียงและเวลา
